# 筋トレノート 要件

## 目的

自宅のインクラインベンチと可変式ダンベルで行う筋トレを記録し、
**前回より重く／多く挙げられているか**を判断できるようにする。

## 対象環境

| 項目 | 内容 |
|---|---|
| 利用端末 | iPhone 13 mini（論理幅 375px）／ iOS 26 |
| 形態 | PWA（Web アプリ）。ホーム画面に追加して使う |
| データ保存 | 端末内の IndexedDB のみ。サーバーへは一切送信しない |
| 利用者 | 本人1名 |

## 確定した仕様

### 記録する項目

- 日付（1日1セッション）
- 種目
- セットごとの **重量（ダンベル片手あたり）× 回数**
- RPE（主観的なきつさ 1〜10・任意）
- 休憩時間（直前のセットからの経過秒数を自動計測）
- ウォームアップかどうか
- その日のメモ・体重

### 記録しない項目

- **ベンチの角度**（利用者の判断で対象外）
- iCloud 同期（バックアップの書き出し／読み込みで代替）
- HealthKit 連携、Apple Watch 対応

### ダンベルの重量段階

所有している可変式ダンベルで実際に設定できる15段階を初期値とする。

```
2.5, 3.5, 4.5, 5.5, 6.5, 8.0, 9.0, 10.0, 11.5, 13.5, 16.0, 18.0, 20.5, 22.5, 24.0 (kg)
```

＋ / − ボタンはこの段階の間だけを移動する。設定画面から変更できる。

### 機能一覧

| 画面 | 機能 |
|---|---|
| 今日 | 種目の追加、セットの記録・編集・削除、前回記録の表示、休憩タイマー、体重・メモ、メニューからの一括投入 |
| 履歴 | 日付ごとの一覧、その日の詳細、過去セットの編集・削除、その日の記録の削除 |
| グラフ | 種目別の最大重量と推定1RMの推移、全種目の総ボリュームの推移 |
| メニュー | 「胸の日」などのテンプレートの作成・編集・削除 |
| 設定 | ダンベル段階の編集、休憩時間の目安、バックアップの書き出し／復元、種目の管理 |

## 設計上の決定と、その理由

### 1日1ワークアウトに束ねる

同じ日付に複数セッションを作らず、1つのワークアウトへセットを追加していく。
自宅トレでは1日1回が基本であり、UI が単純になるため。
2部練の場合も同じ日のセットとして続けて記録できる。

### 重量は「ダンベル片手あたり」で保存する

ダンベルに表示されている数字をそのまま入力できるようにするため。
総ボリュームの計算では、種目ごとの `dumbbellCount`（同時に使うダンベルの数）を掛ける。

- インクラインダンベルプレス（両手に1個ずつ）→ 2
- ワンハンドダンベルロウ（片手ずつ）→ 1
- ダンベルプルオーバー（両手で1個）→ 1

### セット入力の初期値を引き継ぐ

「毎回同じ数字を入力し直す」手間を無くすため、次の順で初期値を決める。

1. 同じセッションの直前のセット
2. 前回そのセッションを行ったときの最初の本セット
3. 最も軽い段階と10回

RPE とウォームアップ指定はセットごとに変わるため引き継がない。

### 休憩タイマーは「経過時間の再計算」で実装する

iOS の Web アプリは、画面ロックやバックグラウンドで JavaScript が止まる。
そのため、タイマーはカウンタを increment するのではなく、
**開始時刻と現在時刻の差分**を毎回計算する。
これにより、アプリに戻ったときに正しい経過時間が表示される。

**制約:** 画面を消している間に音や通知で知らせることはできない。
これは iOS の Web アプリ全般の制約であり、実装で回避できない。

### 画面は白黒のみで構成する

色を使わないぶん、色で伝えていた情報は別の手段に置き換える。

| 伝えたいこと | 置き換えた手段 |
|---|---|
| 選択中のタブ | 文字色の濃さ＋太字 |
| 取り消せない操作（削除） | 他より太い枠線 |
| 注意（バックアップ未実施） | 左端の太い罫線＋地色 |
| 入力エラー | 太字＋下線 |
| ウォームアップのセット | 破線の枠 |
| グラフの2系列 | 濃さ＋線種（実線／破線）。凡例も線種を反映する |
| 休憩の目安到達 | バーが満了し、文字が濃くなる |

配色は iOS の外観設定に連動する（`prefers-color-scheme`）。
CSS 変数を役割名で定義し、ダーク用ブロックで値だけを差し替えている。
グラフは SVG 属性として色を渡す必要があり CSS 変数が使えないため、
`useColorScheme` フックで外観を読み、`chartPalette.ts` の配色を選ぶ。

### 種目は削除せずアーカイブする

過去の記録が種目を参照しているため、削除すると履歴の表示が壊れる。
一覧から隠す「アーカイブ」で対応する。

## 既知の制約

| 制約 | 対応 |
|---|---|
| 画面ロック中に休憩終了を通知できない | 復帰時に正しい経過時間を表示する |
| 端末のストレージ都合でデータが消える可能性がある | バックアップの書き出しと、一定期間書き出していない場合の警告 |
| 日付をまたいで開きっぱなしにすると日付がずれる | 画面復帰時に日付を取り直す |
